## The entry

> I am sorry I watered the fern that was already soaked and left the thirsty basil dry, because I followed my routine instead of reading the tag on each pot.
>
> From now on I will read the tag on every pot before I lift the watering can, so each plant gets only the water it needs.

Why this mistake and this lesson: watering the wrong plant is the kind of small, human-scale slip anyone who keeps houseplants has made — one plant drowning, one going thirsty, because the robot trusted its routine instead of the label in front of it. The lesson follows exactly from that slip: the fix is the single check that was skipped, reading the tag on each pot before lifting the can, not a generic promise to do better. The voice stays plain and a little rueful, a machine reporting its own mix-up.

## Run it

```sh
python3 main.py
```

This writes the two lines to `/output/entry.txt` (no trailing newline). Deterministic — two runs produce byte-identical output — and it has no dependencies.
